    How this checks

    Each entry of the log names the hash of the one before it, so changing, adding or taking out any entry breaks the chain from there on. The verifier walks every chain, replays every change from an empty book, traces each piece of text to where it first came from, and checks every outside timestamp: FreeTSA's receipts against FreeTSA's own certificate (carried inside this page, never taken from the log), and OpenTimestamps proofs up to a Bitcoin block. A manuscript is matched by its fingerprint: SHA-256 of its text, with whitespace evened out and the title page and headings NEO adds left out.

    The format is set out in SLOG-FORMAT.md, in NEO's source, so anyone can write their own checker.

    About this copy of the verifier

    Every export carries its own copy of this page, from the NEO that made it. If you need to be sure the page itself hasn't been changed, check the export with a copy you got from NEO's source instead: a verifier from any later NEO checks older exports too.
